# Coca-Cola Sales & Distribution Performance Dashboard

## 📊 Project Overview

This project uses Microsoft Power BI to analyze Coca-Cola sales and distribution performance across regions, beverage brands, retailers, and delivery companies. The interactive dashboard transforms raw sales data into meaningful business insights, helping users understand sales trends, product performance, profitability, and regional performance.

## 🎯 Objectives

- Analyze overall sales, units sold, operating profit, and operating margin.
- Track month-over-month changes in sales, volume, and profitability.
- Compare performance across regions, beverage brands, retailers, and delivery companies.
- Identify key sales trends and business performance patterns through interactive visualizations.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX (Data Analysis Expressions)** — KPI calculations and time intelligence
- **Microsoft Excel** — Source dataset

## 📁 Dataset

The dataset contains **3,744 records and 14 columns**, covering sales and distribution data for 2022.

Key fields include:
- Retailer and Retailer ID
- Invoice Date
- Region, State, and City
- Beverage Brand
- Days to Deliver and Delivery Company
- Price per Unit and Units Sold
- Total Sales, Operating Profit, and Operating Margin

## 📈 Key Performance Indicators

The dashboard features four primary KPIs:

- **Total Sales:** $8.22M
- **Total Units Sold:** 16.48M
- **Operating Profit:** $3.04M
- **Operating Margin:** Approximately 37%

Month-over-month measures and trend indicators were also created to compare performance with the previous month.

## 📊 Dashboard Features

- KPI cards with trend indicators
- Monthly sales trend analysis
- Regional sales comparison
- Beverage brand sales analysis
- Retailer performance comparison
- Delivery company performance analysis
- Geographic sales analysis
- Interactive slicers for exploring the data

## 🔍 Key Business Insights

- December recorded the highest monthly sales at approximately $984.7K.
- The West region led regional sales with approximately $2.37M.
- Coca-Cola was the leading beverage brand by sales, contributing approximately $1.92M.
- Walmart recorded the highest retailer sales at approximately $4.40M.
- Sales declined by approximately 26.7% from August to September.

These insights demonstrate how the dashboard can help users explore performance differences across time, products, regions, and retail partners.

## ⚙️ Project Workflow

1. Connected the Excel dataset to Power BI.
2. Cleaned and transformed the data using Power Query.
3. Prepared the data model for analysis.
4. Created DAX measures for KPIs and month-over-month comparisons.
5. Developed interactive visualizations and dashboard elements.
6. Analyzed the results to identify key business insights.
